The problem

An AI that can move money is a risk you cannot easily interrupt.

1.3 billion people

According to the WHO, about 1.3 billion people live with a significant disability. Many cannot use a standard keyboard or mouse, and voice and gaze are their main way in.

Hard to intervene

If an AI agent hallucinates or is hijacked, a user who cannot quickly grab the controls has no safety net. Prompts and app-level checks can be bypassed. A contract's rules cannot.

How it works

Four steps from intent to a verified payment.

  1. 1

    Speak or look

    Voice commands, plus eye-gaze cursor control from a webcam.

  2. 2

    Orchestrator routes

    One agent picks the right specialist: System, Vision, Writer or Wallet.

  3. 3

    Guardian confirms

    Every money action waits for the human: say "confirm", double-blink, or press a button.

  4. 4

    GuardVault enforces

    The contract checks the limits and records how the payment was approved.

On-chain guardrails

The AI proposes. The contract decides.

Each user has a vault and a policy stored in the GuardVault contract. Rules live on-chain, so a compromised agent cannot talk its way around them.

Per-transaction limit

Any single payment above the cap reverts.

Daily limit

Total spend per UTC day is capped, however many small payments are tried.

Trusted contacts only

Optionally allow payments only to names saved in the user's on-chain contact book.

Approved agent key

Only the owner or one designated agent key can call the vault. Change or revoke it any time.

Approval method, recorded forever

Every payment logs whether it was approved by voice, double-blink or button, creating a permanent, auditable trail.

Verified and open

Source verified on Sourcify and MonadVision. Inspect it.

Why now

Accessibility meets agent spending.

Local multimodal models now run on a laptop, making voice and gaze control practical. At the same time, AI agents are starting to spend money, and nobody has settled how to limit them.

Consumer accessibility

A subscription for people who rely on voice and gaze, with safe payments built in.

Agent spend-policy infrastructure

Enterprises and developers need enforceable limits for agents that hold funds. GuardVault is a starting point.

Policy-as-a-service

Hosted policy templates, audit trails of human approval, and caregiver or guardian controls.

Run it yourself

Try it on a Mac in a few commands.

git clone https://github.com/callmeharshh/halo
cd halo
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env     # add your keys
python main.py
